Fluxo operacional definido

A execução foi estruturada para impedir dispersão:

PENDENTE
  -> PRONTO
  -> ATIVO
  -> RAMIFICAÇÃO_ATIVA
  -> EM_VALIDACAO
  -> CONCLUIDO

Também foram definidos os estados:

BLOQUEADO_EXTERNO
REABERTO

As regras principais são:

Um único fluxo vertical crítico global por vez.
No máximo uma tarefa-pai ativa em cada setor.
Uma ramificação só pode ser aberta para fechar a tarefa-pai atual.
A próxima onda não começa enquanto houver sucesso falso, risco de tenant, escrita sem auditoria ou perda de correlação.
Uma integração bloqueada por credencial não é considerada concluída.
Toda conclusão exige evidência operacional.
